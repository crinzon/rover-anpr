# Распознавание российских автомобильных номеров

Проект ANPR для ровера: детектор YOLO26n находит номер, а OCR
распознаёт текст и подтип российского регистрационного знака.
Результаты доступны через FastAPI и веб-стенд для проверки фотографий.

## Возможности

- Детекция нескольких номеров в кадре и OCR на основе трансформера.
- 29 подтипов номеров и класс `unknown` в модели распознавания.
- Трекинг, подтверждение номера по разным кадрам и относительная позиция.
- Переподключение USB/RTSP с таймаутами и ограниченной задержкой повторов.
- Очередь доставки в API с повторами и дедупликацией событий в SQLite.
- Сохранение истории и снимков; выгрузка CSV в веб-стенде.

## Требования и модели

Для локальной разработки используется Python 3.11 и виртуальное окружение.
Поддержаны CPU, CUDA и локальный Mac/MPS; Docker на Mac работает на CPU.
В новом клоне нет весов. Разместите их вручную по путям:

- `checkpoints/plate_detector.pt`
- `checkpoints/plate_recognizer.pt`

Источник моделей и права их использования нужно проверить самостоятельно.
[Размещение весов и локальных ресурсов](docs/local-resources.md).

## Локальный запуск ровера

Команды ниже рассчитаны на macOS/Linux и выполняются из корня проекта:

```sh
make install
cp .env.example .env
make run
```

Копируйте шаблон только если собственного `.env` ещё нет.
Перед `make run` настройте `VIDEO_SOURCE` и `DEVICE`: `cpu`, `cuda` или `mps`.
Для Hikvision укажите свой RTSP URL; учётные данные храните только локально.
API доступен на `http://127.0.0.1:8000`.
`GET /plates` возвращает текущие номера, `GET /history` — историю.
`GET /health` проверяет готовность HTTP-приложения, но не камеры или OCR.

Остановка — `make stop`. Команда `make purge` останавливает процессы
и удаляет `.run` с PID и логами; база, снимки и модели сохраняются.
[Подробности запуска, настроек и хранения](docs/deployment.md).

## Проверка фотографий

После установки зависимостей и размещения моделей запустите веб-стенд:

```sh
python full_stand/app.py --port 8080
```

Откройте `http://127.0.0.1:8080`; загрузите фотографии и выгрузите результаты в CSV.
[Установка на Windows, параметры стенда и конвейер](docs/web-stand.md).

## Docker

По умолчанию Compose использует CPU. Модели подключаются только для чтения
из локального `checkpoints/` и не входят в образ или build context.
Проверка конфигурации — `make docker-config`, сборка — `make docker-install`,
запуск — `make docker-run`, остановка — `make docker-stop`.
[CUDA override, права volumes и ограничения USB/Mac](docs/deployment.md).

## Проверки качества

```sh
.venv/bin/pip install -r requirements-dev.txt
make check
```

Команда проверяет Ruff, форматирование и изолированные тесты.
Тесты не требуют камеры, сети и загрузки моделей.
Обучение, источники данных и синтетика описаны в
[отдельной инструкции](docs/data-and-training.md).

## Ограничения

Камера использует ограниченный гражданский формат валидации номера.
ROS2 Humble и ONVIF Profile G пока не реализованы; Hikvision и CUDA требуют
проверки на целевом оборудовании. Docker-сборка ранее не была проверена.
Очередь доставки находится в памяти и может терять события при переполнении.
Веса, глифы генератора, секреты и пользовательские снимки не публикуются.
Права на исключённые ресурсы не подтверждены; общая лицензия проекта
пока не оформлена. Не публикуйте `.env` и архивы рабочего каталога.
